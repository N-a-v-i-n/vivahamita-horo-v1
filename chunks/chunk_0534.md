- (6) Dasa periods of various rasis in this dasa system are found just like in Narayana dasa. 

Suppose lagna is in Ge and Ge is stronger than Sg. Then dasas start from Ge. Because Ge is an odd sign, we go in the forward order and get dasa order as: 

Ge (1<sup>st</sup> ), Vi (4<sup>th</sup> ), Sg (7<sup>th</sup> ) , Pi (10<sup>th</sup> ), Cn (2<sup>nd</sup> ), Li (5<sup>th</sup> ), Cp (8<sup>th</sup> ) , Ar (11<sup>th</sup> ), Le (3<sup>rd</sup> ), Sc (6<sup>th</sup> ), Aq (9<sup>th</sup> ) , Ta(12<sup>th</sup> ). 

Suppose lagna is in Ta and Ta is stronger than Sc. Then dasas start from Ta. Because Ta is an even sign, we go in the _backward_ order and count houses in the backward direction. We get dasa order as: 

Ta (1<sup>st</sup> ), Aq (4<sup>th</sup> ), Sc (7<sup>th</sup> ) , Le (10<sup>th</sup> ), Ar (2<sup>nd</sup> ), Cp (5<sup>th</sup> ), Li (8<sup>th</sup> ) , Cn (11<sup>th</sup> ), Pi (3<sup>rd</sup> ), Sg (6<sup>th</sup> ), Vi (9<sup>th</sup> ) , Ge (12<sup>th</sup> ).
