For example, finding (Moon – Sun + Lagna) is equivalent to finding how far Moon is _from_ Sun and taking the same distance _from_ lagna. If we start from the longitude of Sun and go zodiacally till the longitude of Moon and do _not_ find lagna on the way, then we have to add 30º. The list of important sahams is given in Table 74. For most sahams, the formula given as (A – B + C) is for daytime charts. For nighttime charts, it changes to (B – A + C). This will not be explicitly mentioned for each saham and a mention will be made only when there is a difference.
