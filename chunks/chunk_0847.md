Lagna moves by 30º if the birthtime changes by 120 minutes. If the birthtime changes by _m_ minutes, lagna changes by ( _m_ /120)x30 = ( _m_ /4)º. Moon moves by 3º20' (one quarter of a nakshatra) in 6 hours or 360 minutes. So, if the birthtime changes by _m_ minutes, Moon’s longitude changes by ( _m_ /360)x(3º20'). So the fraction of the nakshatra occupied by Moon that is already traversed by Moon, changes by ( _m_ /360)x(3º20')/(13º20')= _m_ /(360x4). When we find this as a fraction of the zodiac, the change is 360ºx _m_ /(360x4) = ( _m_ /4)º. The error in Sree Lagna is the sum of the error in lagna and the error in this fraction of zodiac. So Sree Lagna changes by ( _m_ /4)º + ( _m_ /4)º = ( _m_ /2)º.
