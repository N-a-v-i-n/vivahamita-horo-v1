Rasis aspect other rasis based on the following rules: 

- A _movable_ rasi aspects all _fixed_ rasis except the one adjacent to it. 

- A _fixed_ rasi aspects all _movable_ rasis except the one adjacent to it. 

- A _dual_ rasi aspects all other _dual_ rasis. 

For example, Ar is a movable sign. It aspects all the fixed signs except the one adjacent to it, _i.e._ Ta. So Ar aspects Le, Sc and Aq. 

Ta is a fixed sign. It aspects all the movable signs except the one adjacent to it, _i.e._ Ar. So Ta aspects Cn, Li and Cp. 

Ge is a dual sign. It aspects all other dual signs. So Ge aspects Vi, Sg and Pi.
